# Adeptus Astartes — Легионы Космического Десанта

Интерактивная энциклопедия по 18 легионам Первого Основания из вселенной Warhammer 40,000.

## Возможности

- **Каталог легионов** — 9 лоялистов и 9 предателей с подробными карточками: примарх, родной мир, хронология, ключевые персонажи, книги
- **Карта галактики** — схематичная звёздная карта с расположением ключевых локаций, маршрутов легионов и фильтрацией по легиону
- **SVG-эмблемы и фигуры** — каноничные эмблемы и фигуры космодесантников в цветах каждого легиона
- **Готический интерфейс** — стилизация под терминал WH40K: металлическая текстура, боевые повреждения, голографические карточки

## Технологии

Vanilla HTML/CSS/JS, без фреймворков и CDN. Полностью офлайн.

- `index.html` — точка входа
- `style.css` — готический визуальный стиль
- `data.js` — данные 18 легионов
- `map-data.js` — 62 локации и 5 сегментумов
- `app.js` — рендеринг и интерактив
- `tools/svg-assets.js` — генератор SVG-ассетов (Node.js)
- `tools/validate.js` — валидатор целостности данных

## Локальный запуск

```bash
python -m http.server 8123
```

Открыть `http://localhost:8123` в браузере.

## Генерация ассетов

```bash
node tools/svg-assets.js
```

Перегенерирует все SVG-эмблемы, фигуры космодесантников и hero-баннер.

## Лицензия

Фан-проект. Warhammer 40,000 является интеллектуальной собственностью Games Workshop. Все визуальные элементы созданы как оригинальные SVG-иллюстрации.
