# Adeptus Astartes — интерактивная энциклопедия легионов (дизайн)

Дата: 2026-08-02
Статус: утверждено пользователем, готово к планированию реализации

## Цель

Автономная (offline, без сборки и CDN) HTML-страница с систематизированной информацией по 18 Легионам/Орденам Адептус Астартес Первого Основания: лор, персонажи, эмблемы, текущий статус, лоялист/еретик, и интерактивная схематичная карта галактики с локациями и событиями каждого легиона.

## Охват контента

18 легионов Первого Основания (I–XX, кроме утраченных/стёртых из истории II и XI, которые не включаются — по ним почти нет канона):

**Лоялисты (9):** Dark Angels (I), White Scars (V), Space Wolves (VI), Imperial Fists (VII), Blood Angels (IX), Iron Hands (X), Ultramarines (XIII), Salamanders (XVIII), Raven Guard (XIX).

**Отступники/Хаос (9):** Emperor's Children (III), Iron Warriors (IV), Night Lords (VIII), World Eaters (XII), Death Guard (XIV), Thousand Sons (XV), Sons of Horus/Black Legion (XVI), Word Bearers (XVII), Alpha Legion (XX).

Для каждого легиона — поля данных:
- Номер, название, статус (лоялист/еретик), примарх (кратко: характер, судьба)
- Родной мир, культура рекрутов
- Текущий статус: лоялисты — как существуют сейчас как Орден-наследник после Второго Основания (раскол на дочерние ордена, где применимо); еретики — нынешняя роль в силах Хаоса
- Цвета доспехов + эмблема (описание мотива)
- Ключевые персонажи помимо примарха (капитаны, герои/антигерои)
- Хронология ключевых событий (4–8 пунктов), каждое привязано к локации (система/планета) с кратким описанием своими словами
- Появления в книгах/сериях (циклы «Ересь Хоруса», романы Warhammer 40,000) — списком названий, без цитирования текста

Контент пишется по устоявшемуся канону из собственных знаний модели, формулировки полностью оригинальные (без копирования текста вики/энциклопедий).

## Визуальные активы

- Один параметрический SVG-генератор фигуры космодесантника (силуэт в силовой броне), инстанцируется на 18 файлов `assets/marines/<legion-slug>.svg` с цветами и эмблемой на наплечнике конкретного легиона.
- 18 оригинальных SVG-эмблем `assets/emblems/<legion-slug>.svg` — узнаваемые по лору мотивы (не копии официальных логотипов GW): напр. Ultramarines — Ω, Blood Angels — капля крови, World Eaters — латунный клыкастый череп, Alpha Legion — гидра, и т.д.
- Все изображения — локальные файлы, подключаются относительными путями, без интернета и внешних библиотек.

## Интерактивная карта

- Отдельная вкладка «Карта галактики» (наравне с вкладкой «Ордена»).
- Схематичная (не астрономически точная — в каноне 40k нет реальных координат) SVG-карта с ~60–80 именованными локациями: родные миры + ключевые места событий каждого легиона (Isstvan III/V, Никея, Молех, Простеро, Синус Клюстер и т.д.), часть точек общие для нескольких легионов.
- Переключатель ордена сверху карты (+ режим «Все»). При выборе легиона: подсветка его локаций, соединяющая линия в хронологическом порядке событий, остальные точки приглушены.
- Клик по точке — попап с описанием события(-й) в этом месте для выбранного легиона; если точка используется несколькими легионами — показывается вклад каждого.

## Структура страницы

- Шапка: заголовок + фильтр «Лоялисты / Отступники / Все»
- Вкладка «Ордена»: сетка карточек-превью (эмблема, название, бейдж статуса) → клик открывает детальную карточку (портрет, эмблема, примарх, родной мир, статус, персонажи, хронология, книги)
- Вкладка «Карта галактики»: как описано выше
- Тёмная тема в духе 40k: тёмный фон, золото/сталь для лоялистов, багровые/хаос-акценты для еретиков; только системные шрифты

## Технический стек

- `index.html` — разметка, CSS, JS-логика рендера
- `data.js` — массив данных по 18 легионам (контент отделён от логики)
- `assets/marines/*.svg`, `assets/emblems/*.svg` — 36 SVG-файлов
- Vanilla HTML/CSS/JS, никаких CDN/npm/сборки. Открывается двойным кликом по `index.html`, работает полностью офлайн.

## Деплой

- Репозиторий: `https://github.com/matresher/wh40k` (пользовательский, на момент старта пуст)
- `index.html` кладётся в корень репозитория (не в подпапку) — так GitHub Pages может отдавать его напрямую с ветки `main` без доп. настройки пути
- Локальная работа: коммиты создаются в этом клоне; **push в удалённый репозиторий — только после отдельного явного подтверждения пользователя**, отдельно от подтверждения самого дизайна/плана
- Включение GitHub Pages (Settings → Pages → Source: Deploy from a branch → `main` / `/(root)`) — пользователь делает сам в интерфейсе GitHub, либо просит сделать явно; это изменение настроек репозитория и не выполняется по умолчанию

## Вне охвата

- Легионы II и XI (утрачены из канона, недостаточно материала)
- Тысячи Орденов-наследников более поздних Основ (только сами 9 лоялистских легионов + краткое упоминание, что они дали начало множеству дочерних орденов)
- Реальные загружаемые изображения из интернета/фан-вики (авторские права) — вместо них оригинальные SVG
